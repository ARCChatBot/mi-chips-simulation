About the model

A student moves through five training layers of rising complexity. Each layer has a 75% prerequisite gate: a layer counts only if it and every layer before it scored at least 75%.

C = complexity weight of the highest layer cleared P̄ = mean score of the cleared layers LV = (C · P̄) / (100 · T_seconds) z = −5.17 + Σ wᵢ · sᵢ (cleared layers only) − 0.00015 · T_seconds + 3200 · LV p̂ = 1 / (1 + e^(−z))
LayerComplexity CᵢScore weight wᵢ

Tiers: blocked at any gate → Red (gate blocked); otherwise p̂ ≥ 85% → Green, 50–85% → Yellow, under 50% → Red (high risk).
